Run locally

Requirements: Python 3.10+ and Git.

1. Clone the repository

git clone https://github.com/Sumaya04122006/Data-Detective.git
cd Data-Detective

2. Create a virtual environment

python -m venv .venv

Activate the environment:

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

3. Install dependencies and launch

pip install -r requirements.txt
python app.py

Open the local URL displayed in your terminal.

Understanding the results

DataDetective AI uses Isolation Forest, an unsupervised machine-learning algorithm that identifies observations that are relatively easy to isolate from the rest of a dataset.

- The contamination parameter influences the expected proportion of observations classified as anomalies.
- An unusual record is not necessarily incorrect or fraudulent.
- Results depend on the selected features, data quality, and model settings.
- Cleaning operations can affect the dataset and subsequent analysis.

Use the results as a starting point for investigation, not as definitive judgments.
